# 全返商城 + 旅游系统

## 项目说明
基于 mall4j 二开的全返商城系统，支持现金全返 / 现金+返点 / 纯返点三种模式，附带旅游线路报名模块。

## 核心功能
### 全返商城
- 三级全返模式：现金全返(15%) / 现金+返点(35%) / 纯返点(50%)
- 大转盘抽奖触发全返
- 返点兑换实物（线下门店核销）
- 四级角色：用户 / 门店 / 编辑 / 管理员
- LBS 就近门店推荐

### 旅游线路
- 线路管理（图文/视频/价格/成团人数）
- 用户报名（姓名+手机）
- 到店支付确认

## 技术栈
- **后端：** SpringBoot 3.x + MyBatis-Plus + Redis + MySQL
- **管理后台：** Vue3 + Element Plus
- **移动端：** uni-app (H5 + 小程序)
- **部署：** 前端 → Cloudflare Pages，后端 → VPS

## 分支策略
- `main` — 稳定版
- `dev` — 开发分支
- `feature/*` — 功能分支
